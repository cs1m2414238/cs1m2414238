## 🛰️ NTRIP Client & GNSS Rover System

Developing the rover-side component of an **NTRIP-based GNSS/RTK correction distribution system**.

### System Flow

```text
GNSS Base Station
       │
       ▼
  RTCM 3.x Source
       │
       ▼
   NTRIP Caster
       │
       │ TCP / NTRIP
       ▼
   NTRIP Client
       │
       ▼
  RTCM Processing
       │
       ▼
 GNSS / RTK Rover
```

### My work includes

* C++17 NTRIP Client
* Linux POSIX socket programming
* TCP/IP communication
* NTRIP v2-style requests
* Mountpoint handling
* RTCM 3.x binary streaming
* Binary-safe buffering
* RTCM frame inspection
* Rover simulation
* Stream-health monitoring
* Future RTK engine integration

### Tech

`C++17` `Linux` `WSL` `TCP/IP` `POSIX Sockets` `NTRIP` `RTCM 3.x` `GNSS` `RTK` `CMake`
